# Spiralographie Studio V6 — Color Studio Edition

Application web artistique autonome, développée en HTML5 Canvas, JavaScript pur et Web Workers.

## Nouveautés V6
- **Color Studio (Mode BOTH)** : Coloration simultanée des traits de spirale et remplissage intelligent des espaces intermédiaires.
- **4 Modes Artistiques** : Noir & Or (champagne, bronze, cuivre), Dégradé Artistique (suivi de spirale, radial, linéaire, circulaire), Couleur Sélective et Multicolore dynamique.
- **Moteur de remplissage des espaces** : Masques et régions connectées avec tolérance réglable et protection des traits.
- **Fonds personnalisables** : Couleurs unies, thèmes sombres/papiers et support de la transparence pour les exports.
- **Export Projet JSON** : Sauvegardez et rechargez l'intégralité de vos configurations de coloration et de géométrie.
- **Interface par onglets** : Ergonomie optimisée sur ordinateur et tablettes iPad.

## Utilisation
1. Ouvrir `index.html` dans un navigateur moderne (ou via un serveur local comme `python -m http.server`).
2. Importer une image (portrait, paysage, illustration).
3. Configurer le Color Studio et les styles géométriques.
4. Exporter en PNG, SVG, PLT ou JSON.
