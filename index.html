GUIDE RAPIDE

Créer votre première œuvre

  1. Importez une photo ou chargez le portrait de démonstration.
  2. Choisissez un style dans la liste. Chaque style utilise une construction de courbes différente.
  3. Ajustez les tours, le contraste et la fidélité. Les changements relancent le rendu.
  4. Exportez en PNG pour l'impression ou en SVG pour agrandir sans pixellisation.

Le mode « Spirale continue » dessine un chemin continu dans l'image. Les autres styles utilisent plusieurs courbes. Cette application produit des œuvres graphiques génératives : elle ne garantit pas une reproduction photographique parfaite.
